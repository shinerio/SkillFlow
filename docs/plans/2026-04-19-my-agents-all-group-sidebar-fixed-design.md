# 我的智能体-全部分组栏固定设计

## 背景

当前“我的智能体 -> 全部”页面中，分组栏和 skill 列表共享页面级滚动容器。用户向下滚动 skill 列表时，左侧分组栏会一起离开视口，导致拖拽 skill 到分组时看不到落点，交互中断。

## 目标

- 在“我的智能体 -> 全部”页面中保持分组栏持续可见。
- skill 列表继续支持长列表滚动。
- 拖拽 skill 到分组时，左侧分组栏始终作为可见的投放目标。
- 不改变“我的智能体”其它页面和模式的滚动行为。

## 方案

采用“双滚动上下文拆分”方案，而不是依赖 `sticky`：

1. 页面外层内容区在“全部”页切换为 `overflow-hidden`，不再承载主滚动。
2. 中间主内容区域保持固定高度的双栏布局。
3. 左侧分组栏独立成为一个可滚动面板，仅在分组过多时内部滚动。
4. 右侧 skill 网格区域独立滚动，承载长列表浏览。

这样处理后，用户滚动 skill 时只会滚动右侧内容区，左侧分组栏位置保持不变。

## 取舍

### 方案 A：拆分左右独立滚动

- 优点：行为稳定，拖拽目标始终可见，不依赖复杂的 `sticky + overflow` 组合。
- 缺点：需要调整“全部”页内容容器的布局层级。

### 方案 B：仅给分组栏加 `sticky`

- 优点：改动更小。
- 缺点：当前页面已有多层 `overflow`，`sticky` 在不同高度和嵌套滚动容器下容易失效或表现不一致。

结论：采用方案 A。

## 影响范围

- `cmd/skillflow/frontend/src/pages/ToolSkills.tsx`
- `cmd/skillflow/frontend/src/components/AgentSkillGroupSidebar.tsx`
- 前端单测，补一个针对“全部”页滚动模式的回归用例

## 验证

- “我的智能体 -> 全部”页面中，向下滚动 skill 列表时，左侧分组栏持续可见。
- skill 可拖拽到任意可见分组。
- 分组过多时，左侧分组栏自身可以滚动。
- 非“全部”页仍保持原有页面滚动行为。
